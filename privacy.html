Privacy Policy

Training Log Sync is a personal Google Apps Script used only by its owner.

Data accessed

With the owner's consent, the script reads read-only Google Health data: exercise sessions, steps, resting heart rate, heart rate variability, sleep, weight and body fat.

How data is used

The data is written only to the owner's own Google Sheet. It is not sold, shared, sent to any third party, or used for advertising. No data is stored anywhere other than that sheet and Google's own services.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
